Por qué importa el ID de catálogo

Sin el mlId (el MLM… de la ficha /p/MLM…) la API de Mercado Libre no entrega precio: el link meli.la no contiene el producto y la API devuelve 403 para IDs de publicación. Un producto sin ID queda con el precio congelado en el que se escribió a mano.
