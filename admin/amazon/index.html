Importación manual

Reglas de importación

  • Se conserva el JSON original completo.
  • Los precios se guardan como observaciones históricas, no como precios vigentes.
  • Los enlaces cortos se conservan como referencia; no se consideran afiliados verificados.
  • Todos los productos nuevos quedan en estado Pendiente.
  • Los ASIN ya existentes o repetidos dentro del archivo se señalan y no se importan automáticamente.
